# SSR skeleton

This is the source template, not an installed workspace app. Copy its contents
into `apps/<name>`, set `name` in package.json and app.config.js, and optionally
copy `.env.sample` to `.env`. There is no create-app command yet.

From the repository root:

```sh
npm install
npm run dev -- <name>
npm run build -- <name>
npm run start -- <name>
```

Home and About are sample pages in `src/pages`, with routes in `src/routes`.
The app owns its Header, Footer and public navigation. Unknown routes return
the core 404 page. No features, API service or authentication provider is required.

`BaseLayout` accepts `header`, `footer` and `extras` React nodes. With no header
or footer supplied, it renders only the content. `backToTop` is opt-in; cookies
and debugging widgets can be passed through `extras`. `BaseHeader` and
`BaseFooter` provide neutral semantic wrappers and accept standard HTML props.

Editor aliases are generated by dev/build; do not copy
jsconfig.json or compiled files into this template.

Environment priority: shell, app .env, app.config.js defaults. Server variables
are read at runtime. `document` options are compiled into the HTML; rebuild after
changing them. Public files keep their URLs (public/favicon.svg → /favicon.svg).
Set SSR_DISABLED=false to test SSR in development; true selects client HMR.
